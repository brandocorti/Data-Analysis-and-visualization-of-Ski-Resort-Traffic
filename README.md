# 🎿 Cortina d’Ampezzo Ski Lift Traffic Analysis  
**Multidimensional data modeling and interactive Tableau visualizations for my Bachelor’s thesis project**

---

## 📌 Overview

This repository contains the full analytical workflow developed for my thesis focused on the **affluence to ski lifts in the Cortina d’Ampezzo area**.  
The project integrates:

- **Operational turnstile data** from the Freccia nel Cielo ski lift operator  
- **Meteorological data** (temperature, wind, snowfall) from ARPA Veneto  
- A **multidimensional data model (Constellation schema)**  
- **SQL scripts**, preprocessing steps, calculated fields  
- A complete set of **interactive Tableau dashboards**

The goal is to analyse seasonal trends, weekly patterns, weather impacts, and skipass behaviours across multiple winter seasons.
